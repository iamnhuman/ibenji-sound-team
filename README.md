# IBENJI Sound Team

Открой `index.html` напрямую или запусти `npm start` и перейди на http://127.0.0.1:4173.
Установка пакетов и сборка не нужны.

38 эмблем автоматически анимируются на Canvas и сменяют друг друга каждые три секунды. Пиксельная диафрагма, схлопывание в луч, сдвиг плёночных полос и ступенчатый каскад чередуются. Каждый переход занимает четверть секунды. Кнопки рядом с лентой и клавиши ← / → переключают кадры. Лента показывает четыре пронумерованные миниатюры и следует за активным кадром. Клик по миниатюре перематывает к её фрагменту. Home и End переходят к первому или последнему кадру, когда фокус на миниатюрах.

Исходники готовых эмблем и логотипа в шапке лежат в `img/done`. Остальные изображения лежат в `img/todo`.

Реактор вернулся под №24. В ленте пропущены №25 и №32, их исходники хранятся в `img/done`. Стартовый масштаб просмотра составляет 65%.

№26–29 добавлены из четырёх присланных изображений в том же порядке. Это космическая эмблема, красные быки, красный вектор и металлическая надпись.

№30–40 добавлены из `img/todo`. Под №40 появился механический змей с вращающимися шарнирами.

Эмблемы пикселизуются непосредственно из оригинальных PNG. Для каждой клетки берётся ближайший пиксель исходника, а компактные палитры убирают мягкие промежуточные оттенки. Портреты и баннеры вписываются в квадратный Canvas с чёрными полями. У №1 моргает глаз и вращается подсветка ореола поверх исходного рисунка. У №2 язык высовывается двумя движениями, у №10 двигаются исходные сегменты и лапы сороконожки.

Кнопки 1000, 500, 200, 100 и 50 меняют детализацию и задают точные размеры холста, PNG и GIF. При открытии выбрано 500 px. Начиная с 200 px надписи используют более мелкую сетку, чтобы сохранялись тонкие штрихи оригинальных букв. Стрелка скачивания сохраняет текущий кадр PNG. В меню GIF пункт Full сохраняет весь цикл, а Current slide сохраняет три секунды выбранного логотипа. Масштаб просмотра меняется кнопками «−» и «+» или колёсиком в зоне в полтора раза шире и выше центрального кадра. У логотипа в шапке загорается пламя при наведении.

`pixel-originals.js` содержит пиксельные версии оригиналов. `pixel-art.js` анимирует их детали, `motion.js` собирает переходы, `brand.js` анимирует кота из `img/done/ibenji_color_02.png`, `pixel-export.js` собирает PNG и GIF. Для файлов 1000, 500, 200, 100 и 50 основные сетки содержат 144, 125, 112, 100 и 50 клеток по стороне. Для №13 используется более крупный пиксель, а на детальных сценах сетка тоньше. У каждого кадра GIF собственная палитра.

`npm run check` проверяет соответствие исходникам, сохранение надписей при анимации, пять разрешений, стыки, пламя и размеры файлов в Node. Браузер для проверок не запускается.

Чтобы обновить пиксельные данные после замены оригинальных PNG на macOS:

```sh
swift -module-cache-path /tmp/ibenji-swift-cache scripts/read-originals.swift "$PWD" /tmp/ibenji-original-rgba
npm run originals -- /tmp/ibenji-original-rgba
```

Соответствие номеров, файлов и областей анимации задано в `scripts/original-sources.json`. Исходные PNG при сборке не изменяются.
